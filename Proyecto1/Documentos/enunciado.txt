1.3.  Objetivo  SMART  
 
SMART  Deﬁnición  Objetivo  redactado  
Especíﬁco  (¿Qué?)  
El  objetivo  es  concreto  y  tangible.  
Diseñar  e  implementar  una  solución  completa  de  Business  Intelligence  para  la  empresa  SG-Food,  desarrollando  un  proceso  ETL  con  SSIS,  un  Data  Warehouse  en  SQL  Server  y  un  modelo  analítico  en  SSAS  para  el  análisis  de  ventas  e  inventarios.  
Medible  (¿Cuánto?)  
El  objetivo  tiene  una  medida  objetiva  de  éxito.  
El  proyecto  se  considerará  cumplido  al  entregar  un  sistema  funcional  con  el  proceso  ETL  operativo,  el  Data  Warehouse  correctamente  implementado,  el  modelo  SSAS  procesado  y  documentación  técnica  que  describa  las  fases  y  resultados.  
Alcanzable  (¿Cómo?)  
El  objetivo  debe  ser  posible  con  los  recursos  disponibles.  
El  objetivo  puede  lograrse  utilizando  las  herramientas  de  Microsoft  (Visual  Studio,  SSIS,  SSAS  y  SQL  Server)  y  aplicando  los  conocimientos  adquiridos  sobre  modelado,  integración  y  análisis  de  datos.  
Realista  (¿Para  qué?)  
El  objetivo  contribuye  a  metas  más  amplias.  
Fortalece  las  competencias  prácticas  en  arquitectura  de  datos,  integración  y  modelado  analítico,  alineadas  con  las  necesidades  reales  de  organizaciones  que  gestionan  grandes  volúmenes  de  información.  
A  Tiempo  (¿Cuándo?)  
El  objetivo  tiene  fecha  límite  o  mejor  aún  un  cronograma  de  hitos  de  progreso   
Debe  completarse  conforme  al  cronograma  del  curso  del  semestre  2026-1,  dentro  del  período  asignado  para  el  desarrollo  del  proyecto  ﬁnal.
